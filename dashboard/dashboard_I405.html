S3 candidate comparison

speed-only vs. anchored reference

Raw S3 measures pure speed-only inference. Period-specific S3 changes parameters by period. Anchored S3 preserves the period-specific shape but rescales each period to observed weekday volume; it is intended for synthetic reference generation, not as a pure speed-only accuracy score.
